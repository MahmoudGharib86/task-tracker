# خطة تنفيذ الإدارة المالية | أكتوبر 2026

واجهة عربية تفاعلية باللغة العربية مع الخط `Mahmoud-Final.ttf`.

## الرفع على GitHub Pages
1. أنشئ مستودع GitHub جديدًا، وارفع `index.html` و`Mahmoud-Final.ttf` إلى جذر المستودع (بنفس أسماء الملفات).
2. من **Settings → Pages** اختر **Deploy from a branch** ثم **main / (root)** واضغط Save.
3. افتح رابط GitHub Pages الذي يظهر في الإعدادات.

## الوظائف
- عرض 8 مهام، الخطوات التفصيلية، المسؤولين، المواعيد، والمخرجات.
- تعديل/إضافة/حذف أي مهمة أو خطوة وإضافة ملاحظات.
- تعليم إنجاز كل خطوة بنقرة واحدة.
- نسب الإنجاز تحتسب حسب ساعات الخطوات، وليس بعددها فقط.
- حفظ تلقائي عبر `localStorage` على نفس المتصفح والجهاز.
- تصدير JSON احتياطي واستيراده على جهاز آخر.
- بحث وتصفية ومخطط زمني وطباعة.

**مهم:** الاستضافة عبر GitHub Pages ثابتة. التعديلات على الصفحة لا تُكتب إلى GitHub ولا تتزامن تلقائيًا بين الأجهزة. احتفظ بنسخة احتياطية JSON بانتظام. للحصول على تزامن حقيقي بين الأجهزة، يلزم ربط النظام بقاعدة بيانات وخدمة تسجيل دخول (مثل Supabase).
